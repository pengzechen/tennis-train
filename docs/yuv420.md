从 ONNX 到 v4 (YUV420) cvimodel 的完整命令。全部在 tpu-mlir 容器内、/workspace/tpu_convert 目录下执行(进容器:docker exec -it tpu-mlir bash,然后 cd /workspace/tpu_convert)。

前提:ONNX 必须是 opset 17、480×640
若还没导出,在 Windows 主机上跑(容器里的 onnxruntime 只支持到 opset 19,opset 20 会在 --test_input 阶段报错):


from ultralytics import YOLO
YOLO(r"runs/detect/runs/tennis/train2/weights/best.pt").export(
    format="onnx", imgsz=[480, 640], opset=17, simplify=True)
# 生成 runs/.../weights/best.onnx  →  拷进 tpu_convert/
① ONNX → MLIR(顺带生成 FP32 参考输出用于比对)

model_transform.py \
  --model_name yolov8n_tennis \
  --model_def best.onnx \
  --input_shapes [[1,3,480,640]] \
  --mean 0.0,0.0,0.0 \
  --scale 0.0039216,0.0039216,0.0039216 \
  --keep_aspect_ratio \
  --pixel_format rgb \
  --test_input ../dataset/valid/images/001a8a1a132eeed0_jpg.rf.5f50a0bda30577d6c694b8535dcd7507.jpg \
  --test_result yolov8n_tennis_top_outputs.npz \
  --mlir yolov8n_tennis.mlir
注意:这里 --pixel_format rgb 是模型的原生输入;YUV→RGB 的转换是在 deploy 阶段 用 --fuse_preprocess 加进去的,transform 阶段不写 YUV。

② 生成 INT8 校准表(约 100 张真实图)

run_calibration.py yolov8n_tennis.mlir \
  --dataset ../dataset/valid/images \
  --input_num 100 \
  -o yolov8n_cali_table
③ MLIR → v4 cvimodel(融合 YUV420 预处理 + 混精度)⭐

model_deploy.py \
  --mlir yolov8n_tennis.mlir \
  --quantize INT8 \
  --calibration_table yolov8n_cali_table \
  --quantize_table shape_pattern_qtable \
  --processor cv181x \
  --fuse_preprocess \
  --aligned_input \
  --customization_format YUV420_PLANAR \
  --test_input ../dataset/valid/images/001a8a1a132eeed0_jpg.rf.5f50a0bda30577d6c694b8535dcd7507.jpg \
  --test_reference yolov8n_tennis_top_outputs.npz \
  --tolerance 0.85,0.45 \
  --compare_all \
  --model yolov8n_tennis_v4.cvimodel
三个关键 flag(缺一不可)
flag	作用	漏了会怎样
--quantize_table shape_pattern_qtable	把检测头 /model.22/*(含 Sigmoid 分数分支)保留 F16	纯 INT8 会把分数量化成 0 → 零检测(而且 output0 相似度还很高,坑)
--fuse_preprocess + --customization_format YUV420_PLANAR	让 TPU 内部做 YUV420→RGB + 归一化	模型仍要 RGB 输入,起不到卸载 CPU 的作用
--aligned_input	输入按 VPSS 对齐(本例 640/320 已 64 对齐,紧密 460800 字节无 padding)	板子上 buffer 布局对不上
shape_pattern_qtable 已在 tpu_convert/ 里,内容是把 24 个 /model.22/* 层设为 F16(表头虽写 # chip: bm1684x,但 F16 在 cv181x 上被接受)。若要重新生成,用 run_qtable.py(本机容器没装,所以直接复用了这张表)。

产物:tpu_convert/yolov8n_tennis_v4.cvimodel,输入是紧密 I420 460800 字节(Y→U→V,BT.601 limited range)。

跑完可直接用 tools/yuv_tpu_demo.py 验证:


python3 /workspace/tools/yuv_tpu_demo.py \
